# ChainTrace

## Blockchain OSINT Visualizer

ChainTrace is a blockchain investigation platform that visualizes Ethereum wallet transactions, detects suspicious fund flows, enriches wallet addresses using OSINT labels, and generates forensic investigation reports.

## Features

- Ethereum wallet investigation
- Interactive transaction graph
- Suspicious activity detection
- OSINT label enrichment
- Risk analysis dashboard
- Forensic report generation

## Technologies Used

- HTML
- CSS
- JavaScript
- React (CDN)
- Cytoscape.js
